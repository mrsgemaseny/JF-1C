# Журнал разработки — JF-1C (ZhanFinance)
Дата: 2026-10-20

## Сессия: Внедрение трех-уровневой системы защиты SPA от сбоев загрузки чанков при деплоях (Vite Chunk Load Error Recovery)

### 1. Контекст задачи
- **Проблема**: При выкатке новых версий фронтенда в продакшн старые хэшированные чанки удаляются. Пользователи с открытыми вкладками при навигации сталкиваются с ошибкой `Failed to fetch dynamically imported module`, приводящей к сбою дерева React Router и неработоспособности приложения без ручного принудительного обновления вкладки.
- **Цель**: Реализовать надежное инфраструктурное решение по стандарту ADR `vite-chunk-load-error-recovery-adr.md` с тремя эшелонами защиты, телеметрией Sentry, безопасным хранилищем и защитой от бесконечных циклов перезагрузки (anti-reload storm).

### 2. Реализованные изменения

#### А. Инфраструктурный модуль восстановления чанков (`chunkRecovery.ts`)
1. **Унифицированная детекция ошибок (`isChunkLoadError`)**:
   - Покрыты все сигнатуры браузерных движков: Chromium/Vite (`Failed to fetch dynamically imported module`), WebKit/Safari (`Importing a module script failed`), Gecko/Firefox (`error loading dynamically imported module`), Webpack/Rollup (`ChunkLoadError`, `Loading chunk`, `Loading CSS chunk`).
2. **Анти-штормовой барьер (`triggerChunkReload`)**:
   - Предотвращает зацикливание перезагрузок при отсутствии сети или сбоях хостинга: разрешена ровно одна автоматическая перезагрузка за сессию (`jf_chunk_reload_lock`).
   - При повторном сбое блокирует `window.location.reload()` и делегирует ошибку уровню `ErrorBoundary` для показа понятного UI.
   - Обернуто в безопасный доступ к `sessionStorage` с перехватом `SecurityError` / `QuotaExceededError` (приватный режим, строгие iframe).
   - Интегрирована телеметрия через `Sentry.addBreadcrumb`.
3. **Автоматический сброс замка (`markChunkLoadSuccess`)**:
   - При успешной загрузке компонента или ручном сбросе ошибки в `ErrorBoundary` блокировка снимается, обеспечивая прозрачные перезагрузки при последующих деплоях.

#### Б. Интеграция Уровней 1, 2 и 3
1. **Уровень 1 (Перехватчик предзагрузки Vite в `main.tsx`)**:
   - Внедрен вызов `initVitePreloadErrorRecovery()` до монтирования корневого дерева React.
   - Перехватывает нативное событие `vite:preloadError`. При первой ошибке вызывает `event.preventDefault()` и перезагружает страницу; при активном замке позволяет ошибке всплыть в `ErrorBoundary`.
2. **Уровень 2 (Роутерный Lazy-загрузчик `lazyWithRetry.ts`)**:
   - Интегрирован с `chunkRecovery.ts`: при сбое динамического импорта инициирует контролируемый релоад и возвращает незавершенный `Promise`, предотвращая крах дерева React до завершения выгрузки страницы.
3. **Уровень 3 (`ErrorBoundary.tsx`)**:
   - Переведен на унифицированный детектор `isChunkLoadError`.
   - В метод `handleReset` добавлен вызов `markChunkLoadSuccess()` для гарантированного сброса блокировки при клике пользователем на кнопку «Обновить страницу».
