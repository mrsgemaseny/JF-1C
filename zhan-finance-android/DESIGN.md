# DESIGN.md — ZHAN FINANCE Android Mobile Client

## 1. Философия и Визуальный Канон (Zero-Deslop Monochrome & Emerald)
- **Базовая палитра (Dark-First Enterprise)**:
  - Canvas (основной фон экранов): `#0a0a0c`
  - Surface (карточки, панели, навигация): `#18181b` (`zinc-900`)
  - Surface Elevated (модальные шторки, инпуты, активные элементы): `#202024`
  - Border (разделители и контуры карточек): `rgba(255, 255, 255, 0.08)` (`border-white/10`)
  - Brand Accent (основное действие, активные статусы): `#10b981` (`emerald-500`), активное нажатие `#059669` (`emerald-600`)
  - Semantic Statuses:
    - Warning / Pending: `#f59e0b` (`amber-500`)
    - Danger / Overdue / Rejected: `#ef4444` (`red-500`)
    - Info / In Progress: `#3b82f6` (`blue-500`)

## 2. Строгая 4-уровневая типографика
Иерархия строится через насыщенность (`font-medium`, `font-semibold`, `font-bold`) и контраст цвета (`text-zinc-100`, `text-zinc-300`, `text-zinc-400`, `text-zinc-500`), а не раздуванием кегля:
1. **Level 1 (`text-xs` / 12px)**: Метаданные, таймстампы, коды счетов, статусные метки, подписи таб-бара.
2. **Level 2 (`text-sm` / 14px)**: Основной текст карточек задач, сообщений чата, вторичные кнопки, поля ввода.
3. **Level 3 (`text-base` / 16px)**: Заголовки карточек, названия компаний, суммы счетов в списках, основные кнопки действий.
4. **Level 4 (`text-lg` / 18px — `text-xl` / 20px)**: Заголовки экранов в AppBar и ключевые финансовые показатели дашборда.

## 3. Геометрия, Отступы и Интерактивность
- **Радиусы**: Строгие сдержанные радиусы (`rounded-md` / 6px для инпутов и кнопок, `rounded-lg` / 8px для карточек). Никаких декоративных капсульных плашек (`rounded-full`) над заголовками.
- **Touch Targets**: Минимальная зона нажатия любого интерактивного элемента на Android — `44x44dp`.
- **Обратная связь**: Тактильный отклик (`expo-haptics`) при захвате задачи из пула, смене статуса, успешной оплате и биометрической верификации.
- **Запреты**: Полный запрет на эмодзи в UI и коде, запрет на декоративные градиентные пятна и визуальный шум.
